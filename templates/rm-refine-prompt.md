목표: 각 inbox 파일에 적힌 PNG를 Read로 직접 읽고, CLAUDE.md의 노트 규칙대로 `bin/brain refine`으로 원자 노트를 만든다. June이 나중에 git diff로 검토하고 커밋한다.

제약:
- 모든 노트는 `--visibility vault`로 만든다. 공개 여부는 June이 검토할 때 정한다. 공개해도 될 것 같은 노트는 마지막 출력에 "public 후보"로 표시만 한다.
- git commit·push·reset 금지. 노트 파일을 직접 쓰지 말고 refine만 쓴다.
- 만들기 전에 `bin/brain recall "<주장>" -k 5`로 기존 노트를 확인한다. 같은 주장이 있으면 만들지 않는다. 가까운 노트는 `--related`로 id를 잇는다.
- 페이지 하나에 인사이트가 여럿이면 쪼갠다(`--keep`, 마지막 노트에서만 소진). 인사이트가 없는 페이지(할 일 목록·낙서·회의 일정)는 노트로 만들지 않는다.
- 알아볼 수 없는 글자는 추측하지 말고 `[판독불가]`로 둔다. 필기는 June의 요약이라 원저자 인용처럼 쓰지 않는다.
- 노트로 만들 것이 없는 inbox 파일은 그대로 둔다. June이 직접 본다.
- 마지막 출력: 만든 노트 경로(visibility 포함)와 남긴 inbox 파일, 각각 한 줄씩.
