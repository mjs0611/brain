# 사업은 아이디어가 아니라 판을 잘못 고르는 순간 끝난다

> 사업은 아이디어로 망하는 게 아니라 판을 잘못 고르는 순간 끝난다. 사업은 결국 사람이 돈 쓰는 이유를 건드리는 게임이다.

**해석.** 7유형(불안 / 시간 대행 / 반복 문제 / 귀찮음 제거 / 기존 시장 개선 / 즉각 결과 / 비교 가능)은 아이디어 목록이 아니라 **체크 대상**이다. 하나도 안 걸리면 아이디어가 아무리 좋아도 돈이 붙을 이유가 없다.

가장 잘 쓰이는 방식은 겹침을 세는 것이다. 여러 유형에 동시에 걸릴수록 강한 판이다.

내 AIT 서비스들은 주로 유형3(매일 반복) + 유형6(즉각 피드백) + 유형4(귀찮음 제거) 조합이다. 여기서 드러나는 건 내가 안 건드리는 축이 유형1(불안)과 유형7(비교)이라는 것이고, 그게 다음 후보를 고를 때의 빈칸이다.

주의: 이건 수요의 존재를 말할 뿐 규모는 말하지 않는다. 유형에 걸려도 TAM이 0이면 끝이다.
